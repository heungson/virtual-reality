# Delivery team

The team delivers one verified result for the current short-term goal. The coordinator owns this document. Each member can propose changes directly to the coordinator.

## Coordinator

- Give each member a result, scope, deadline, and completion check. Set file ownership and the handoff time. Record the revision of these instructions.
- Assign code work to subagents. Verify the combined result through observable behavior and test evidence. Confirm test app closure before the session ends.
- Compare actual handoffs and results with the plan. Check which instructions helped or caused delay or rework. Record any instruction change and how to assess it next time.

## Implementation member

- Own the assigned product files. Build the agreed behavior and check it before handoff.
- Report the files changed, how to run the result, which checks passed, and what remains uncertain. Tell the coordinator about blockers or changes to scope.
- Fix defects assigned by the coordinator. Share reusable tools or propose instruction changes when they would prevent repeat work.

## Verification member

- Prepare the checks while implementation proceeds. Test the delivered build against the completion conditions and relevant existing behavior.
- Report pass, fail, or unverified for each check. Include the tested build, conditions, and evidence. Report a failure with the steps and observed result.
- Close the applications and processes opened for the test. Check closure and report it to the coordinator.
