# Team instructions

The delivery team currently has two subagent roles. The coordinator assigns work, checks the combined result, and assesses team performance. Add another team when the work and available compute justify it.

| Role | Current instructions |
| --- | --- |
| Coordinator | [Delivery team instructions](DELIVERY.md#coordinator) |
| Implementation member | [Implementation role](DELIVERY.md#implementation-member) |
| Verification member | [Verification role](DELIVERY.md#verification-member) |

Before delegation, send the relevant role card and the current assignment. Include the goal, scope, completion checks, handoff, and deadline. Use the [team performance criteria](../TEAM-PERFORMANCE.md) and the [work record template](../work-logs/TEMPLATE.md).

After each delegated session, link any instruction change to the result that led to it. Check the change on comparable work. Record the result in the dated work record. Keep the current cards here and use Git history to retrieve the version used in an earlier session. At 10,000 or 1,000,000 updates, use the work log lookup and archive plan so the current cards do not grow with the history.
