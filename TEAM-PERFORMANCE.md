# Team and coordinator performance

Criteria revision 1. Use the dated work record for evidence. Link the active goals in GOALS.md and record the Git revision or a short description that identifies those goals. Use consistent team and member IDs. If a member is replaced, give the new member a new ID and keep the role name when it is the same.

| ID | Measure | Check |
| --- | --- | --- |
| TEAM-01 | Accepted results | Count accepted deliverables over assigned deliverables for each team and member. A result is accepted when its specified checks pass. Record blocked and cancelled items separately. |
| TEAM-02 | Delivery time | Record planned and actual handoff times. Count handoffs that meet their agreed deadline. Record the cause of each delay, including outside dependencies. |
| TEAM-03 | Rework | Count results that need correction after handoff. Record the missed condition and who can prevent it next time. |
| COORD-01 | Assignment clarity | Before delegation, check that every assignment has an owner, scope, expected result, deadline, and verification method. Record missing items and any conflict in file ownership. |
| COORD-02 | Coordination cost | Record time spent waiting for handoffs or resolving overlap when measurable. Compare it with the session time and identify one avoidable delay if there is one. |
| COORD-03 | Verification and improvement | Link each accepted result to evidence. Record one management change when an issue warrants it. Set a check for the next comparable session, then compare the results. |

At each goal review, summarize the relevant records for each team and member across the short-, mid-, and long-term goals. Use counts and evidence links. Mark unknown values as unknown. Compare similar assignments and record differences in scope or constraints. Assess the simulation separately with QUALITY.md.

Keep this catalog small. Store session evidence in the dated work logs and goal summaries in the records where the goals are reviewed. At 10,000 updates, add a generated lookup by goal, team, member, and criterion if retrieval slows. At 1,000,000 updates, use an indexed archive if measured costs justify it. Preserve IDs, criteria revisions, and links.
