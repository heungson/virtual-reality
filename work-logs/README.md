## File structure

Keep one file per work period in a month folder. Use the path `YYYY-MM/YYYY-MM-DD-HHMM.md`, with dates and times in Korea Standard Time. If a file name already exists, add a number. Never replace an existing record with a new period.

Use TEMPLATE.md for new records. Create the month folder when its first record is needed.

## Use and maintenance

1. Read this index and the latest record before planning work. Read older records only when needed.
2. Check the records for today's date before a scheduled start. Skip the scheduled period if a period is already recorded, unless the user requests another. If a previous record is still open, inspect it and record its actual state before starting new work.
3. Create the work record before starting the selected task. Update the latest-record link in this index.
4. Complete the record at the end of the period. Update the current state above with the next window, next task, and available token allowance.
5. Keep this index short. Store detailed results in the work records.

The agent can change this structure when a different method improves access or maintenance. Preserve past records and update links, project rules, and scheduled instructions that use changed paths. Record the reason for the change.
