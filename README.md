# VirtualReality

## Ultimate goal

Create a virtual reality that simulates the human world.

This is the original ultimate goal. The AI agent must preserve it. Under Rule 5 in AGENTS.md, the agent can improve, add, or remove other goals and project rules to support it.

## Decisions still required

- Define who will use the simulation and why.
- Define which parts of the human world the simulation must include.
- Define the first version and its completion criteria.
- Define the required devices, software, and resource limits.

The long-term goal does not define the scope of the first version.
