# Human assessment record

Use one record per session. Use a participant number. Explain the observations and let the participant choose whether to take part.

- Evidence type: human observation or agent rehearsal.
- Date, prototype version, browser, and input devices:
- Prior experience with this prototype:
- Task: Put the cup on the yellow stand. Use the instructions on the page.
- Result: Complete, incomplete, or ended early. Record elapsed time.
- Observations: Object recognition, controls, unsuccessful actions, recovery, and help needed.
- Optional activity: After completion, let the participant continue or leave. Record optional active time, including zero, and actions such as exploring or restarting. Record idle time separately. Note any interruption or test time limit.
- Comments volunteered by the participant:
- Interpretation: Record possible causes and what the evidence cannot show.
- Follow-up: Record the most important issue and how to check an improvement.

Use the first human session as a baseline. Compare sessions under similar conditions. An agent rehearsal does not count as a human session.

Start the optional observation when the task status reports completion. End it when the participant leaves, ends the assessment, or reaches the test time limit. Use an external timer. Note when the participant begins and stops interacting. Record idle intervals separately. If you cannot tell whether a pause is idle time or deliberate observation, mark it as uncertain. Record a restart as an action in the same optional period.
